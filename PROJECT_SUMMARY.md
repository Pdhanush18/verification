## 🔄 How to Customize

### Change Primary Color
1. Open `tailwind.config.ts`
2. Find `'primary': '#003d9b'`
3. Change to your color
4. Save and refresh - instant update!

### Add New Section
1. Create `components/NewSection.tsx`
2. Add content with className styling
3. Import in `app/page.tsx`
4. Add to the JSX

### Modify Typography
1. Edit `tailwind.config.ts` fontSize section
2. Change font family, size, weight, line-height
3. Apply with `className="text-display-lg"`
